# My Hyprland and Waybar dotfiles

My dotfiles for Hyprland and Waybar

# Required packages:

kitty, nautilus, rofi-wayland, gnome-keyring,hyprpolkitagent, swaync, wl-clipboard, awww, JetBrains Nerd Fonts, grim, slurp, cliphist.

# Installation

WARNING! By installing these dotfiles, you may break your system. Install them at your own risk!

1. Run the following command in your terminal: `git clone https://github.com/kirieshka228-govno/hypr-waybar-dots.git`
2. Go into the hypr-waybar-dots directory
3. Run `cp -r hypr ~/.config && cp -r waybar ~/.config` (WARNING! THIS COMMAND WILL OVERWRITE YOUR CURRENT CONFIGS! USE AT YOUR OWN RISK!)
4. Reboot the system to fully apply the configs
5. Done!
